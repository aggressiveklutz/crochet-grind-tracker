#Crochet Grind Tracker

A gamified crochet learning and progress tracker for people who would rather grind XP than "practice."

## About

Crochet Grind Tracker (CGT) turns learning crochet into a progression system.

Instead of following one long course, skills are broken into small challenges. Complete the required tasks, earn XP, unlock achievements and collect stickers.

The project is currently being built and tested alongside my own crochet learning process — so the curriculum and features evolve based on actual use.

## Current features

- Skill-based learning cards
- Individual task checklists
- XP and level progression
- Achievement stickers
- Optional grind milestones
- Progress saved locally in the browser
- Mobile-first interface

## Current roadmap
